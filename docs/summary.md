# Seeing AROME — project summary

- **Author:** Thomas Hossler (generated with Claude Opus 5.5 via the `project-status` skill)
- **Last updated:** 2026-10-22T21:38:19Z
- **As of commit:** `main` at `7325245`, plus branch `thossler/frontend-replica`

Forecasts astronomical **seeing** (optical turbulence, arcseconds at 500 nm, lower is better) for observing sites from Météo-France **AROME** (1.3 km) GRIB2 output plus an empirical Cn² model ("V2", with K_TKE / K_CIS / K_conv coefficients). Repo owner is a friend who adds research scripts under `research/`; Thomas Hossler builds the product around them.

Read these before deep work — this summary links rather than duplicates:
- `docs/architecture.md` — the contract: DB schema, env vars, API endpoints, seeing_core interface, container/infra names.
- `infra/terraform/README.md` — infra architecture, security model, cost, first-time runbook, IAP fixes.
- `research/README.md` — the original algorithm, explained for beginners.

## Runtime on GCP (`project-astrarome`, us-central1)

Cloud Scheduler → Cloud Run Job `seeing-batch-{env}` (prod 4×/day aligned on AROME 00/06/12/18Z, dev 1×/day) → Postgres 16 container on e2-micro VM `seeing-db` (private IP 10.10.0.10, daily disk snapshots) ← Cloud Run service `seeing-web-{env}` (API + SPA) behind Cloud Run native **IAP**. The app has no auth of its own; `/api/me` reads `X-Goog-Authenticated-User-Email`. Image: `us-central1-docker.pkg.dev/project-astrarome/seeing/web:<sha>`.

Dev env is live; prod was not yet applied as of 2026-10-14.

`make db-up migrate dev-seed`, then `make api-dev` (:8000) and `make web-dev` (:5173, proxies `/api`). Tests: `make test-core test-batch test-api test-web`. Others: `web-image`, `batch-run`, `lint` / `format` (ruff on `research/`).

## Gotchas

- Local ADC belongs to a deleted account: run terraform/gcloud tools with `GOOGLE_OAUTH_ACCESS_TOKEN=$(gcloud auth print-access-token --account <your-google-account>)`.
- Follow the `github` skill: `<area>: <summary>` commit messages, one branch and PR per topic, `red-team` review before every push, and an explicit OK from the user before any push or force-push. `gh` is not installed; open PRs from the compare link.

- Show `terraform plan`, then apply the saved plan separately after user approval.
